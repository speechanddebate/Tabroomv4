# Design System

The colors, type, and surfaces every Tabroom page is built from. The tokens
live in the `@theme` block of `src/app.css`, and Tailwind turns each one into
utilities: `--color-primary-strong` gives `bg-primary-strong`,
`text-primary-strong`, `border-primary-strong`, and so on.

The color swatches and contrast samples on this page are hard-coded copies of
those values, so update both together. The type and elevation samples render
with the real styles.

## Rules

- Use a token for every color. No hex values and no stock Tailwind palette
  classes (`bg-gray-100`, `text-blue-600`) in components.
- Do not use the numbered shades (`bg-primary-700`, `ring-secondary-300`).
  They exist only so Flowbite's internals resolve to our palette, and they go
  away when Flowbite does.
- `primary` and `accent` are decoration. Text and control edges use
  `primary-strong`, `primary-deep`, or a status color, all of which pass
  contrast on `surface`.
- Never signal with color alone. Links inside prose are underlined, and a
  status color comes with a label or icon.
- Every interactive element shows the same focus indicator:
  `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-primary-strong`.
- Reach for an existing component before styling an element by hand. The
  [component stories](#components) show every variant.

badge and alert backgrounds. The one exception is the solid warning button,
which fills with `accent` and dark text because yellow cannot hold white text.

## Elevation

Four levels, lowest to highest. Three of them are utilities defined in
`src/app.css`; use them instead of combining a background, border, and shadow
by hand.

- Only `shadow-sm`, `shadow-lg`, and `inset-shadow-xs` belong to the system.
  To restyle a level, redefine that `--shadow-*` token in `@theme`.
- Raised and overlay keep their border because forced colors mode drops box
  shadows.
- `sunken` sets no border or radius. A well that runs edge to edge in a card
  takes `border-y`; an inset one takes a full border.
- Tinted surfaces such as alerts and prompts keep their own background and
  add `shadow-sm` directly.

## Shape

- Controls (buttons, inputs) use `rounded`, 4px.
- Cards and overlays use `rounded-md`, 6px, which `raised` and `overlay`
  already set.
- Pills and switch tracks use `rounded-full`.
- Borders are 1px `border` when decorative and `border-strong` on a control,
  where the edge has to reach 3:1.
